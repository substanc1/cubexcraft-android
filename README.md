# CubeX Mobile 3 (Android)

Android-приложение Minecraft-проекта [CubeXCraft](https://www.cubexcraft.site): вход в аккаунт CubeX, установка мобильной
сборки CubeXTech, запуск игры, новости, голосование, друзья. Написано с нуля — без кода Zalith Launcher; работает и на
слабых телефонах (arm64, Android 8+, от 3 ГБ памяти, OpenGL ES 3.2).

**Скачивать — только с https://www.cubexcraft.site.** Сборки из других мест не официальные.

Код открыт для просмотра, чтобы любой мог проверить, что приложение делает на телефоне. Это не open source: копировать,
распространять и делать на его основе свои лаунчеры нельзя — см. [LICENSE](LICENSE). Исключение — библиотека запуска
Java [`core/`](core/) на основе PojavLauncher / Amethyst: она под LGPL-3.0. Сторонние компоненты —
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), уязвимости — [SECURITY.md](SECURITY.md).
