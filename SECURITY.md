# Безопасность / Security

Нашли уязвимость в CubeX Mobile? Не публикуйте её в issues. Сообщите приватно: GitHub → вкладка **Security** →
**Report a vulnerability**, или письмом на admin@cubexcraft.site. Исправление придёт всем через встроенное обновление.

Found a vulnerability in CubeX Mobile? Please report it privately via GitHub → **Security** → **Report a vulnerability**,
or email admin@cubexcraft.site. Do not post it in issues.

Официальные сборки — только с https://www.cubexcraft.site, подпись — сертификат CubeX
(SHA-256 `98b07a07f3d533e764e17ca876474554fe385debb9a54add910c97200a9ce813`). APK с другой подписью — не наш.
